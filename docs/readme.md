# DOCS

Supporting documentation for the site — content briefs, translation sources,
brand and design references, and deployment notes for the hosting provider.
The written record around the project, not the site itself.

- `design-references/` — reference material for making design changes. Each file
  records a layout that was built and evaluated: the intent, the exact CSS and
  markup, and whether it shipped. Read these before reworking a section, so a
  decision that was already tested is not quietly undone.
